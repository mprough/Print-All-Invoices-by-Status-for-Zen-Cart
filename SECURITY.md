# Security policy

## Supported version

Security fixes are applied to the current release only. Please reproduce an issue with the newest version before reporting it.

## Reporting a vulnerability

Do not publish exploitable details in a public GitHub issue. Submit the report through the [PRO-Webs support desk](https://prowebsinc.zohodesk.com/portal/en/newticket) with the plugin version, Zen Cart version, PHP version, relevant log entries, and reproduction steps.

Ordinary bugs that do not expose sensitive information may be reported through the same support desk.
